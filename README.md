# Azure Data Factory CI/CD Automation - Core Repository

## Description
Central repository for demonstrating **CI/CD practices in Azure Data Factory**, focusing on pipeline automation, monitoring, and version control.

## Key Features
- Continuous integration and deployment for ADF pipelines
- Automated trigger setup for pipelines
- Version-controlled linked services, datasets, and pipelines
- Example workflow configurations for multiple environments

## Tech Stack
- Azure Data Factory
- GitHub Actions
- JSON / ARM Templates
- DevOps pipelines

## Usage
1. Clone the repository
2. Configure GitHub Actions with Azure credentials
3. Deploy pipelines automatically across DEV/PROD environments

## Notes
Ideal for learning how to implement production-ready CI/CD pipelines in Azure.
